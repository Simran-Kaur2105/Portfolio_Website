SIMRAN KAUR — RESPONSIVE PORTFOLIO

FILES
- index.html: website structure and content
- style.css: responsive design and visual theme
- script.js: mobile navigation and small interactions
- assets/profile.jpg: supplied profile photo
- assets/skillforge-dashboard.png and skillforge-courses.png: SkillForge screenshots
- assets/quizmaster-dashboard.png and quizmaster-question-bank.png: QuizMaster screenshots

HOW TO VIEW
1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Right-click index.html and choose Open with Live Server, or open index.html in a browser.

PROJECTS
- SkillForge AI — Course Builder: frontend-only HTML, CSS and JavaScript application. Course templates and learning interactions run in the browser; progress and scores use localStorage.
- QuizMaster: Python, Tkinter and SQLite desktop quiz application with a question bank, quiz history and CSV export.
